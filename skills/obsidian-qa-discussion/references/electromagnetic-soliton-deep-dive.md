## Key lesson

The user's "why" chain was not random — it followed a **spontaneous deeper-and-deeper trajectory** that naturally ended in a fiction comparison. Each answer satisfied one level, and the user dug to the next. The pattern was:

> What is it? → How does internal force balance work? → What IS that force? → Why doesn't the other side explode? → How does it form initially? → How does nature do this? → How did we figure out it's hollow? → What about the sci-fi version?

An effective approach: **don't front-load everything**. Answer each level fully, wait for the question, then go deeper. The user self-selects the depth.
